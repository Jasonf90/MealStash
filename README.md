# MealStash

Public site for **MealStash**, a recipe app for iPhone and iPad.

Published with GitHub Pages from `/docs` on `main`:

| Page | URL |
| --- | --- |
| Overview | https://jasonf90.github.io/MealStash/ |
| Privacy Policy | https://jasonf90.github.io/MealStash/privacy.html |
| Support & Guide | https://jasonf90.github.io/MealStash/support.html |

The privacy and support URLs are the ones filed with App Store Connect, so
they need to keep resolving for as long as the app is on the App Store.

To edit, change the HTML in `docs/` and push to `main`; Pages redeploys
automatically.
